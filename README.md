# Portfólio — Rafael

Site pessoal responsivo para apresentar habilidades, áreas de atuação, serviços e canais de contato. Não inclui seção de projetos nesta primeira versão.

## Estrutura

- `index.html`: conteúdo e estrutura semântica.
- `css/style.css`: visual, cores e responsividade.
- `js/script.js`: menu mobile e ano automático no rodapé.
- `assets/`: pasta reservada para imagens e ícones locais.

## Como abrir

1. Extraia a pasta do projeto.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

O Google Fonts precisa de internet para carregar as fontes Manrope e DM Sans. Sem internet, o site usa fontes alternativas.

## Antes de publicar

No `index.html`, troque os links de exemplo do GitHub, Instagram, e-mail e WhatsApp pelos seus contatos reais. No link do WhatsApp, use o formato internacional com código do país e DDD, sem `+`, espaços ou traços, por exemplo `https://wa.me/55DDDNUMERO`.

Revise as habilidades e serviços para garantir que descrevem corretamente sua experiência atual. Não anuncie avaliações de segurança sem autorização explícita do responsável pelo sistema.
